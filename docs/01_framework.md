# **1. 概念フレームワークと行動経済学的基盤**

[[00_index|← インデックスに戻る]]

## **1.1 時間的非整合性とコミットメント・デバイス**

人の行動変容を阻害する最大の要因は、個人の意志力の欠如ではなく、認知構造および選択のアーキテクチャにおける不備に存在する。行動経済学において、人間は将来獲得できる大きな便益よりも、目の前にある即時的な快楽や負担回避を過剰に優先する「現在志向バイアス（Present Bias）」および「双曲割引（Hyperbolic Discounting）」のメカニズムに従って行動することが立証されている。計画を立てる自己（Planning Self）と、実行時に誘惑に晒される自己（Tempted Self）の間で時間的非整合性（Time Inconsistency）が生じることが直接的な原因である。

この時間的非整合性を打破し、強制的に行動を遂行させるための動的メカニズムが「コミットメント・デバイス（Commitment Device）」である。コミットメント・デバイスは、将来の選択肢を現在の判断によってあらかじめ制限し、目標からの離脱に対して明確かつ不可逆的なコスト（経済的損失、社会的信用失墜、心理的摩擦）を課すことによって機能する。計画時において合理的な自己が将来の選択肢を拘束し、実行時に誘惑に晒された自己が離脱の代償の高さゆえに行動を完遂せざるを得ない環境を設計することが本システムの根幹をなす。

## **1.2 コミットメント・スタック（3層構造）**

AIを活用した24時間監視・スパルタ型ライフコーチングにおけるコミットメント構造は、単一の制約に依存するのではなく、複数層を組み合わせた「コミットメント・スタック（Commitment Stack）」として統合設計される。単一の制約のみでは回避策が容易に見出されるため、環境的、社会的、経済的な3層の拘束を重畳的に適用する。

| コミットメント層 | 構成要素 | 作用メカニズム | 具体的な実装仕様 |
| :---- | :---- | :---- | :---- |
| **環境的コミットメント** *(Environmental)* | 逃げ道の物理的・デジタル的遮断 | 行動の実行にかかる摩擦（Friction）を減らし、非目標行動の摩擦を極大化する。 | タスク開始時刻におけるLINE通知およびアプリ遮断機能との連動。 |
| **社会的コミットメント** *(Social)* | 監視の可視化と認知的一貫性 | 他者への公開言明、一貫性欲求、および認知的不協和の回避を励起する。 | LINE上でのリアルタイム進捗ログ公開および未達成時の指定グループチャットへの失態自動送信。 |
| **経済的コミットメント** *(Financial)* | 損失回避（Loss Aversion） | 離脱に対して即時的かつ不可逆的な金銭的ペナルティを課す。 | タスク未完了時にアンチチャリティ（受講者が嫌悪する団体）への自動寄付決済を実行する契約。 |

## **1.3 ハード/ソフト・コミットメントと50分ブロックPDCA**

ペナルティの設計は、直接的な金銭的損失等を伴う「ハード・コミットメント」と、恥や自己肯定感の低下といった心理的コストに依拠する「ソフト・コミットメント」を高度に融合させる。

また、現実的かつ持続可能な行動定着を図るため、**50分単位の集中作業ブロック**による計画・実績報告および即時フィードバックのPDCAサイクルを採用する。週1回の従来型コーチングに対し、毎日50分ブロック単位で修正機会を創出し、行動の定着率を大幅に高める。
