## **2.1 UI/UXコンポーネント配置とプロアクティブ通知方針**

LINE公式アカウントのトーク画面は、リッチメニューや各種ボタン（Postback Button）を持たず、ユーザーからの自由なテキスト・画像投稿のみで運用される。

### **現在のUI構成（ボタン全廃・チャット完結型）**

本Botはボタン操作やテンプレートメッセージを一切使用せず、すべてテキスト/画像のチャットメッセージのみで送受信する。

| 操作 | ユーザーアクション | システム挙動 |
| :---- | :---- | :---- |
| **記録・報告** | テキストまたは画像をそのまま投稿 | 投稿内容をログに記録。「記録したよ 👍」を返信し、LINE未確認（IDLE）状態であれば ACTIVE へ復帰させる。 |

### **ユーザー主導の報告・総括ループ**

「開始」「完了」の状態管理や承認フェーズは行わない。

1. **朝のフロー（07:00）**: Google Tasksから当日のタスクを取得し、AIが行動経済学的優先度を自動付与して push（承認フェーズなし）。
2. **50分おきの進捗確認（07:50, 08:40, ...）**: 50分前の状態から「LINE返信」または「タスクの増減（新規追加＋完了）」のどちらも発生しなかった場合、ステータスを「LINE未確認（IDLE）」へ変更し進捗pushを一時停止。
3. **夜の総括（22:00）**: 1日の記録（タスク増減・返信有無）に基づき加点/減点（±5点）を実施し、現在の規律スコア（数値は直接提示せず、100点に近いほど「鬼軍曹」、0点に近いほど「理学療法士」のトーン）に応じた総括を送信する。

### **プロアクティブ通知方針（追いLINE無しの原則）**

ユーザーの利便性と心理的負担に配慮し、**定刻の単発通知のみ**を実施する。
- ユーザーから返信・応答がない場合でも**追撃通知（追いLINE）の連投は行わない**。
- 返信およびタスク増減がない場合はサイレントで「LINE未確認（IDLE）」へ切り替え、pushを安全に一時停止する。

## **2.2 ユーザー状態遷移モデル (FSM)**

対話エンジンは2状態の有限状態機械（FSM: ACTIVE / IDLE）として管理される。

| 状態（State） | トリガーイベント | 挙動 / システム動作 | 復帰・遷移条件 |
| :---- | :---- | :---- | :---- |
| **ACTIVE** | 朝の定刻（07:00）、または未確認からの復帰 | 50分おきに進捗確認メッセージを送信。直近50分に返信もタスク増減もなければ IDLE へ移行。 | 返信あり または タスク増減あり で ACTIVE を維持 |
| **IDLE（LINE未確認）** | 直近50分で返信・タスク増減がゼロの時 | 50分おきの進捗確認 push を一時停止（追撃LINE禁止）。 | ユーザーからのLINE送信、またはGoogle Tasksの増減（新規追加/完了）で ACTIVE へ復帰 |
