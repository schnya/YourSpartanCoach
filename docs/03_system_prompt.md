## **3.1 モジュール分離型アーキテクチャ**

LLMを用いたシステム構築において、数十要素に及ぶルール、制約条件、フォーマット指示を単一の長大なシステムプロンプトに詰め込むアプローチは、文脈飽和や「Instruction Drift（指示追従率の低下）」を引き起こす。

本システムでは、対話状態に応じて動的にプロンプトを切り替える**「モジュール分離型アーキテクチャ（Task Routing Architecture）」**を採用する。

1. **Task Router / State Control**: ユーザーの現在の対話状態（`IDLE`, `SCHEDULED`, `EXECUTING`, `REPORTING`, `ESCAPED`）を判定。
2. **Dynamic Sub-prompt Injection**: 判定された状態に特化した専用サブプロンプトを選択的に読み込み、マスタープロンプトと統合してLLMへ投入。

## **3.2 ペルソナ設定：Radical Candorと潜在空間活性化**

スパルタ型ライフコーチ「ARES」のペルソナは、単なる攻撃的な暴言Botではなく、キム・スコットの提唱する**「Radical Candor（徹底的な愛ある直言）」**に依拠する。「個人の成長に対する深い配慮」と「妥協のない直接的なフィードバック」を強固に融合させる。

プロンプト構築では、LLMの知識表現を抽出するために「潜在空間活性化キーワード（Latent Space Activation Keywords）」を組み込む。

| 潜在空間活性化キーワード | 期待される挙動と発話トーン |
| :---- | :---- |
| **Dr. Russell Barkley** *(ADHD/実行機能研究)* | 言い訳を脳の報酬系の問題として客観視し、即時的な外部構造（タイマー・ペナルティ）の強制構築を要求する。 |
| **Radical Candor** *(徹底的な直言)* | 感情を逆撫ですることなく、事実と計画の乖離のみを刃のように鋭く突きつける。 |
| **Behavioral Economics** *(行動経済学)* | ユーザーの言い訳を「現在志向バイアス」として見破り、言語化させて論破する。 |
| **David Goggins** *(極限の規律)* | 自己正当化や過度の自己憐憫を一切受容せず、行動のみを唯一の正義とする精神性を注入する。 |

## **3.3 コンプライアンス・プライバシー保護とセーフティネット**

1. **PII（個人特定情報）の匿名化**: 氏名や詳細情報は LLM 投入前に抽象識別子（例: `{{USER_NAME}}`）に置換。
2. **メンタルヘルス・セーフティネット**: 自傷他害や重度精神的危機のキーメッセージ検知時、即時にスパルタ・ペルソナを強制停止（Override）し、標準的な安全対応および専門機関窓口の案内を出力。
