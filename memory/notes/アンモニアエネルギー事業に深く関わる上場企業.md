政府の「価格差支援制度」や「拠点整備支援制度」の認定を受けている、あるいはグリーンイノベーション基金（GI基金）で技術開発を主導している企業です。

**1. 燃焼技術・プラントエンジニアリング（技術提供）**

アンモニアを燃やすためのバーナやエンジンの開発、プラント建設を担う企業です。

- **IHI (7013)**

- 世界初の大型商用ボイラでのアンモニア20%混焼実証をJERAと共同で成功させました。
- **アンモニア専焼ガスタービン**の開発を前倒しで完了し、海外展開も進めています。
- インドからのサプライチェーン構築や、北海道苫小牧の拠点整備計画にも中核として参画しています。

- **三菱重工業 (7011)**

- アンモニア専焼バーナの開発に成功し、2030年代の商用化を目指しています。
- 長崎を拠点にアンモニア分解による水素製造の実証なども行っています。

- **川崎重工業 (7012)**

- アンモニア燃料に対応した大型運搬船の建造を進めています。

- **日揮ホールディングス (1963)**

- 福島県浪江町でのグリーンアンモニア製造や、川崎での供給計画に参画しています。

- **千代田化工建設 (6366)**

- GI基金を通じて、世界トップレベルの性能を持つ新合成触媒の研究開発を行いました（一部中止となりましたが、技術的知見を有しています）。

**2. 電力・エネルギー（インフラ・需要家）**

アンモニアを実際に燃料として使い、発電所や輸入基地を運営する企業です。

- **北海道電力 (9509)**

- インド由来のクリーンアンモニア供給計画や、苫小牧地域での大規模な受入・供給拠点整備の認定を取得しています。

- **東京電力ホールディングス (9501) / 中部電力 (9502)**

- 両社が折半出資する**JERA**（非上場）が、碧南火力発電所での実証試験や、米国ルイジアナ州からの大規模なブルーアンモニア輸入計画を主導しています。

- **電源開発 (J-POWER) (9513)**

- 次世代エネルギー循環モデルプロジェクトなどに参画しています。

**3. 総合商社（供給網・物流）**

海外でのアンモニア製造権益の確保や、国際的な輸送網を構築する企業です。

- **三井物産 (8031)**

- 米国ルイジアナ州での「Blue Point」プロジェクトや、苫小牧での供給拠点整備など、複数の大規模計画を推進しています。

- **丸紅 (8002)**

- 苫小牧地域でのアンモニアサプライチェーン構築に向けた共同検討に参画しています。

- **トヨタ通商 (8015)**

- 愛知県での低炭素水素・アンモニア供給計画などに携わっています。

**4. 化学・素材（原料・産業利用）**

アンモニアを燃料や化学品原料として利用し、コンビナートの脱炭素化を進める企業です。

- **レゾナック・ホールディングス (4004)**

- 川崎市で廃プラスチックをガス化して低炭素アンモニアを製造し、供給するプロジェクトを進めています。

- **UBE (4208)**

- インドからのクリーンアンモニア輸入計画や、川崎、周南でのコンビナート連携に参画しています。

- **三菱ガス化学 (4182)**

- インド由来のクリーンアンモニア利活用計画に名を連ねています。

- **住友化学 (4005)**

- 同じくインドからの供給計画に参画し、化学品原料などの脱炭素化を図っています。

- **出光興産 (5019)**

- 山口県周南市の石油備蓄基地をアンモニア輸入拠点に転用する検討を進めています。

**5. 海運・造船・エンジン（輸送・船舶利用）**

アンモニアを運び、また船の燃料として利用する技術を持つ企業です。

- **日本郵船 (9101)**

- 世界初のアンモニア燃料商用タグボートを完成させ、2026年には大型のアンモニア輸送船の竣工を予定しています。

- **ジャパンエンジンコーポレーション (6016)**

- 船舶用の大型アンモニアエンジンの開発を完了しています。

アンモニアは**「既存のインフラを転用できる」**という強みがあるため、上記のように重工業、電力、商社、化学、海運といった日本の基幹産業のトッププレイヤーが多く関わっています。

ソース（出典）に基づき、**「技術的優位性」「公的支援の獲得（リスク低減）」「グローバル標準への関与」**という観点から、投資の検討材料となり得る順にソートしました。

※あくまでソースに基づいた**事業の進捗度や確実性による評価**であり、将来の株価や利益を保証するものではありません。

**1位：IHI (7013)**

**理由：技術の先行逃げ切りと国際標準の掌握**

- **前倒しの成果：** GI基金（グリーンイノベーション基金）事業において、専焼ガスタービンの開発を**当初計画より2年前倒しで完了**させ、GHG（温室効果ガス）削減率99%以上を達成しています。
- **国際標準のリード：** アンモニア燃焼技術の**国際標準化（ISO/TS 21343）を主導**しており、将来的に他国が技術を導入する際の「ライセンス型ビジネス」で優位に立つ戦略を明確に持っています。
- **実機実証の成功：** JERA碧南火力での世界初20%混焼実証においても、同社製のバーナが主要な役割を果たし、無事故・無災害で完遂しました。

**2位：三井物産 (8031) / 東京電力HD (9501) / 中部電力 (9502)**

**理由：15年間の「利益保証」スキームの先駆者**

- **JERAを通じた圧倒的地位：** 東電と中電の折半出資会社であるJERAは、米国ルイジアナ州の「Blue Point」プロジェクトにおいて、**国内第1号の「価格差支援制度」認定**を受けました。
- **リスクの極小化：** この制度は、既存燃料との価格差を**原則15年間にわたり政府が補填**するもので、投資回収リスクが劇的に低い「地域独占インフラ」としての地位を予約したと言えます。
- **商社の調達力：** 三井物産は米国プロジェクトの権益を持ちつつ、苫小牧などの拠点整備にも参画しており、上流（製造）から下流（供給）までを抑えています。

**3位：北海道電力 (9509)**

**理由：地域ハブとしての独占的ポテンシャル**

- **拠点整備の認定：** 2026年3月、苫小牧地域での大規模供給拠点として**「拠点整備支援制度」の認定**を受けました。
- **需要の集中：** 北海道では次世代半導体工場（Rapidus等）やデータセンターの立地が進んでおり、電力需要の増加が見込まれます。苫小牧を北日本のアンモニア供給ハブにすることで、安定的なエネルギーインフラ収益が期待できます。

**4位：三菱重工業 (7011)**

**理由：技術は一流だが、実装スケジュールに遅延**

- **高い技術水準：** 専焼バーナ自体の開発には成功しており、学会賞を受賞するなど技術力は極めて高いです。
- **GI基金からの撤退：** ただし、建設費高騰などの影響で、GI基金の期限内（2030年度末）の実機実証完了が困難となり、**基金枠組みからは撤退**して自社事業（2030年代商用化）に切り替えました。IHIに比べると、短中期的なマイルストーン達成という点で見劣りします。

**5位：レゾナック・ホールディングス (4004)**

**理由：ユニークな地産地消モデル**

- **ケミカルリサイクル：** 廃プラスチックをガス化して低炭素アンモニアを製造する独自モデルを構築しており、川崎コンビナートでの供給計画が認定されています。
- **規模の限界：** 重工業や電力会社のような大規模発電用途に比べると供給量は限定的ですが、既存の化学コンビナート資産を有効活用できる強みがあります。

**6位：千代田化工建設 (6366)**

**理由：革新技術への挑戦が「中止」の判断**

- **研究の中止：** GI基金を通じて取り組んでいた「アンモニア製造新触媒」の開発において、世界トップレベルの性能は出したものの、**商用化の目標には届かず2026年1月にプロジェクトが中止**されました。
- **投資判断：** 「つくる」技術の革新よりも、既存の製法（ハーバー・ボッシュ法）を用いた海外からの大規模輸入が主流になるという市場判断が下された形です。

  

**総括：** 現時点では、**「すでに実証に成功し、国際標準も握りつつあるIHI」**と、**「15年間の政府補填という強力なバックアップを得て、インフラの権利を確保したJERA（東電・中電）と三井物産」**が、ビジネスとしての確実性が最も高いグループであるとソースからは判断できます。
