# アーリーステージVCの出資先リストから業務委託先を探す

**要約**: 資金調達直後のスタートアップは外部委託（デザイン・開発・マーケ等）を探すタイミング。VCのPortfolio一覧＋PR TIMES/STARTUP DBの調達情報で「直近調達＝委託ニーズ高」な企業を絞り、SNSでカジュアル接触するのが有効。

**なぜ有効か**

- 資金調達直後のスタートアップは人手不足なことが多く、外部の業務委託（デザイン、開発、マーケ、バックオフィスなど）を積極的に探している
- VCのポートフォリオページには投資先企業一覧が公開されていることが多く、業種・フェーズもある程度わかる
- 資金調達のプレスリリース（PR TIMES等）と組み合わせると「直近で調達した=採用・委託ニーズが高まっているタイミング」を狙える

**具体的な進め方**

1. VCの公式サイトの「Portfolio」ページを確認(例: East Ventures、ANRI、Coral Capital、Genesia Ventures、DNX Ventures など)
2. PR TIMESやSTARTUP DBで「資金調達」+業界キーワードで検索し、直近1〜3ヶ月の調達企業を絞る
3. 各企業の採用ページやWantedly、Meetyなどで業務委託の募集有無を確認
4. 自分のスキルと合いそうな企業にはSNS(X/LinkedIn)経由でカジュアルに接触するのも効果的

**注意点**

- VCのポートフォリオリストは更新が遅れていたり、Exit/倒産した企業がそのまま載っていることもあるので、最新の状況は個別に確認が必要
- 業務委託の需要は「調達直後〜半年以内」が特に高い傾向があるので、タイミングを意識すると良い

もしご自身の得意分野(エンジニア、デザイナー、マーケ、経理など)を教えてもらえれば、相性の良さそうなVCや業界の絞り込み方も一緒に考えられます。
